# بازبینی امنیتی (فاز ۵): OWASP Top 10 (2021)

این سند بازبینی **کد و پیکربندی** است، نه آزمون نفوذ. هر ردیف به شاهد قابل بررسی ارجاع می‌دهد (تست خودکار، فایل یا فرمان). مواردی که به هاست واقعی وابسته‌اند جدا علامت خورده‌اند و تا فاز ۶ **تأییدنشده** می‌مانند.

## موارد دیگر بررسی‌شده

- **ریدایرکت باز:** مقصد ریدایرکت را فقط مدیر تعیین می‌کند. مقصد باید مسیر داخلی (`/…`) یا نشانی کامل `http(s)` باشد. `//host` و `javascript:` رد می‌شوند و ریدایرکت به خود ممنوع است (`RedirectsTest`).
- **پراکسی و CDN:** پیش‌فرض این است که به هیچ هدر `X-Forwarded-*` اعتماد نمی‌شود. اگر CDN جلوی سایت باشد، باید `TRUSTED_PROXIES` تنظیم شود. در غیر این صورت محدودیت نرخ IP همهٔ کاربران را یکی می‌بیند (D34).
- **CSRF:** همهٔ فرم‌های POST، PUT و DELETE توکن دارند (میان‌افزار `web` لاراول). مسیرهای ناشناختهٔ POST پاسخ ۴۰۴ می‌گیرند، نه ۴۰۵ (`PublicSiteTest`).
- **نشت اطلاعات در محیط غیر production:** همهٔ پاسخ‌ها `X-Robots-Tag: noindex` دارند و robots.txt برابر `Disallow: /` است (D25).

## کارهای باقی‌مانده برای فاز ۶ (روی هاست واقعی)

1. اجرای `php artisan app:check-production`: باید **هیچ FAIL** نداشته باشد و نسخهٔ CLI PHP با نسخهٔ وب یکی باشد (`tools/host-check`).
2. بررسی با `curl -I`:
   - `http://` با ۳۰۱ به `https://` برود.
   - هدرهای امنیتی و HSTS وجود داشته باشند و `X-Powered-By` نباشد.
   - `/.env`، `/storage/` و `/vendor/` پاسخ ۴۰۴ یا ۴۰۳ بدهند.
   - یک فایل `.php` آزمایشی در `public/media` اجرا نشود.
3. فعال کردن ورود دومرحله‌ای برای حساب مدیر، و تغییر مسیر پیش‌فرض پنل (`ADMIN_PATH`).
4. تهیهٔ پشتیبان و **یک بار آزمایش بازگردانی**.
