### هنوز نامعلوم

- نسخه‌های PHP **قابل انتخاب** در DirectAdmin
- افزونه‌های `pdo_mysql`، `intl`، `gd` (WebP)، `fileinfo`، `sodium` و `zip`
- نسخهٔ MySQL یا MariaDB
- دسترسی SSH
- امکان تغییر Document Root یا قرار دادن کد کنار `public_html`
- Cron

## ۳. راهنمای ارتقای PHP (اقدام کاربر، پیش‌نیاز فاز ۲)

> ⚠️ تغییر نسخهٔ PHP روی همین دامنه، **سایت وردپرس فعلی** را هم تحت تأثیر قرار می‌دهد.

### روش پیشنهادی: بدون ریسک برای سایت فعلی

1. در DirectAdmin یک **زیردامنه** بسازید، مثلاً `new.sajadmasoumi.com`.
   - این زیردامنه بعداً محیط Staging هم خواهد بود.
2. اگر پنل اجازه می‌دهد، **فقط برای همین زیردامنه** نسخهٔ PHP را روی **8.4** بگذارید. محل تنظیم: Domain Setup › PHP Version، یا PHP Selector.
3. `host-check.php` (با توکن) را در پوشهٔ زیردامنه آپلود و اجرا کنید، خروجی را بفرستید و فایل را حذف کنید.

### اگر نسخهٔ PHP فقط برای کل حساب قابل تغییر است (CloudLinux PHP Selector)

1. از سایت و دیتابیس فعلی **پشتیبان کامل** بگیرید.
2. Elementor، WooCommerce، Rank Math و بقیهٔ افزونه‌ها را به‌روز کنید.
3. نسخه را روی **8.3** یا **8.4** بگذارید و صفحات اصلی، فرم تماس و پنل وردپرس را بررسی کنید.
4. اگر مشکلی پیش آمد، نسخه را به 8.1 برگردانید و نتیجه را اطلاع دهید.

### اگر هیچ نسخه‌ای بالاتر از 8.2 در دسترس نیست

درخواست از شرکت میزبان یا تغییر هاست. فاز ۲ تا آن زمان شروع نمی‌شود.

همچنین هنگام ارتقا افزونه‌های **`intl`، `pdo_mysql`، `gd`، `fileinfo`، `zip`، `sodium`** را فعال کنید (اگر انتخابی هستند). نسخهٔ دیتابیس را هم از صفحهٔ اول phpMyAdmin یا «سلامت سایت › اطلاعات › پایگاه داده» بفرستید.
