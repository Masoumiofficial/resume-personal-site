## ۱. وضعیت زیرساخت

### ۱.۱ هاست هدف: همه‌چیز **[نامعلوم]**

نسخهٔ PHP، افزونه‌ها، نوع و نسخهٔ دیتابیس، SSH، Composer، تغییر Document Root، Cron، محدودیت‌ها و ایمیل هنوز بررسی نشده‌اند.

برای جمع‌آوری این اطلاعات دو ابزار آماده شده است:

- **`tools/host-check/host-check.php`**: اسکریپت تشخیصی یک‌بارمصرف و فقط‌خواندنی. با توکن محافظت می‌شود، `phpinfo()` و متغیرهای محیطی را نمایش نمی‌دهد و قابلیت حذف خودکار دارد.
  - **آزمون اجراشده:** روی PHP 7.4، 8.2، 8.3 و 8.4 (WASM) بدون خطا اجرا شد.
  - توکن پیش‌فرض، توکن کوتاه، توکن اشتباه و ورودی آرایه‌ای همگی با 404 رد شدند.
  - حذف خودکار فایل تأیید شد.
  - این آزمون‌ها روی **هاست واقعی** انجام نشده‌اند.
- **`docs/phase-0/hosting-checklist.md`**: چک‌لیست مواردی که باید از پنل DirectAdmin یا شرکت میزبان پرسیده شود.

### ۱.۲ مشاهدات زیرساختی سایت فعلی

- **[تأییدشده]** سایت فعلی روی WordPress اجرا می‌شود. افزونه‌های فعال (از فضای‌نام‌های REST): Elementor و Elementor Pro، Rank Math، WooCommerce، Contact Form 7، Jetpack.
  - همچنین فضای‌نام‌های `mcp`، `elementor-mcp-composer/v1.0.18`، `wp-abilities/v1` و `elementor-ai` فعال‌اند.
- **[تأییدشده]** منطقهٔ زمانی وردپرس `UTC+3.5` است.
- **[تأییدشده]** `https://sajadmasoumi.ir/` به `https://sajadmasoumi.com/` هدایت می‌شود. نوع ریدایرکت (301 یا 302) با ابزار فعلی قابل تشخیص نبود.
  - **این ریدایرکت باید بعد از مهاجرت هم حفظ شود.**
- **[استنتاج]** صفحهٔ 404 و نام برخی فایل‌ها به `sajadmasoumi.ir` اشاره دارند. بنابراین دامنهٔ قبلی سایت `.ir` بوده و ممکن است بک‌لینک‌هایی به آن وجود داشته باشد.

## ۴. محدودیت‌های شناخته‌شده

1. **[تأییدشده]** Composer و apt در این Sandbox به مخزن بسته‌ها دسترسی ندارند. ساخت و تست Laravel در CI انجام می‌شود.

3. **[نامعلوم]** همهٔ مشخصات هاست.
4. **[نامعلوم]** دادهٔ Search Console. بدون آن، اولویت‌بندی ریدایرکت‌ها فقط بر اساس Sitemap و REST API است.
5. **[تأییدشده]** مخزن عمومی است. هیچ دادهٔ واقعی کاربر، پیام تماس، Dump دیتابیس یا فایل پشتیبان نباید وارد آن شود.

## ۵. نقشهٔ معماری (Modular Monolith)

```
                    ┌──────────────────────── HTTP (LiteSpeed/Apache) ───────────────────────┐
                    │      Document Root  →  public/   (فقط index.php، build/، media/)        │
                    └──────────────────────────────────────┬─────────────────────────────────┘
                                                           │
   Presentation      routes/web.php ─┬─ Public Controllers (Blade)      ─┐
                                     └─ Admin Controllers (Blade, /admin)│  Middleware: auth, 2fa,
                                                                         │  throttle, security headers,
   Application       Form Requests · Policies · Services (فقط جایی که لازم است)   noindex(admin), redirects
                                                                         │
   Domain Modules    Identity │ Profile │ Resume │ Portfolio │ Blog │ Media │ Contact │ Settings │ SEO │ Audit
                                                                         │
   Infrastructure    Eloquent/MySQL · Filesystem (private + public media) · Mail(SMTP) · File Cache · Scheduler(Cron)
```

| ماژول | مسئولیت | جداول اولیه (دلیل نیاز) |
|---|---|---|
| Identity | ورود، خروج، بازیابی رمز، 2FA، Session | `users` و `password_reset_tokens` (استاندارد)، `sessions` (اگر درایور `database` انتخاب شود) |

## ۸. پرسش‌های ضروری باقی‌مانده

فقط مواردی که مسیر را تغییر می‌دهند:

1. **مشخصات هاست:** خروجی `host-check.php` و پاسخ چک‌لیست `hosting-checklist.md`. حداقل این موارد لازم است:
   - نسخه‌های PHP قابل انتخاب
   - نوع و نسخهٔ دیتابیس
   - دسترسی SSH
   - امکان تغییر Document Root
   - امکان Cron
   - نام شرکت میزبان
2. **CI:** آیا استفاده از GitHub Actions مجاز است؟ آیا مخزن عمومی بماند یا خصوصی شود؟
3. **فروشگاه:** صفحات WooCommerce و محصول «مجوز ساماندهی» چه شوند؟ گزینه‌ها:
   - صفحهٔ خدمت ساده (بدون پرداخت)
   - ریدایرکت 301 به `etehadwp.com/product/samandehi/`
   - حذف با 410
4. **مقالات کپی‌شده از اتحاد وردپرس:** گزینه‌ها:
   - نگه‌داشتن با canonical به etehadwp.com
   - بازنویسی اختصاصی
   - حذف و 301 به نسخهٔ etehadwp
5. **محتوای تأییدنشده:** حذف نظرات ساختگی، «حقایق جالب»، درصد مهارت‌ها و لوگوی Google پیشنهاد می‌شود. آیا جدول قیمت‌ها منتشر شود؟
6. **هویت:** عنوان حرفه‌ای نهایی، ایمیل عمومی (`.ir` یا `.com`) و نمایش یا عدم نمایش شمارهٔ تلفن.
7. **Search Console:** امکان ارسال خروجی «Pages» و «Links» (یا دسترسی خواندنی) برای اولویت‌بندی ریدایرکت‌ها.

> کارهای مستقل از پاسخ‌ها (فاز ۱: نقشهٔ سایت، Design System و مدل محتوایی) را می‌توان هم‌زمان پیش برد.
