# چک‌لیست بررسی هاست (DirectAdmin)

هدف: جمع‌آوری **حداقل** اطلاعات لازم برای انتخاب نسخهٔ Laravel و روش امن استقرار.

> زمان تقریبی: ۱۵ دقیقه

**مهم:** هیچ رمز عبور، توکن یا اطلاعات ورود را در چت یا مخزن Git قرار ندهید. فقط مقادیر فنی خواسته‌شده را ارسال کنید.

---

## روش A: اسکریپت خودکار (پیشنهادی)

1. فایل `tools/host-check/host-check.php` را باز کنید.
2. در خط `const ACCESS_TOKEN = 'CHANGE_ME';` یک رشتهٔ تصادفی **حداقل ۲۴ کاراکتری** بگذارید (مثلاً از یک Password Manager).
   - اگر توکن تغییر نکند یا کوتاه باشد، اسکریپت فقط 404 برمی‌گرداند.
3. در DirectAdmin › **File Manager**، فایل را با نامی غیرقابل حدس به این مسیر آپلود کنید:
   `domains/sajadmasoumi.com/public_html/`
   (مثلاً `hc-7f3a9.php`)
4. این آدرس را باز کنید:
   `https://sajadmasoumi.com/hc-7f3a9.php?token=<توکن>`
5. کل خروجی را کپی کنید و برای تیم بفرستید.
   - خروجی شامل مسیرهای سرور است. آن را عمومی منتشر نکنید.
6. **بلافاصله** فایل را حذف کنید. دو راه وجود دارد:
   - باز کردن `...?token=<توکن>&delete=1`
   - حذف از File Manager

   سپس بررسی کنید که آدرس 404 برمی‌گرداند.

**این اسکریپت چه کاری انجام نمی‌دهد:**

- `phpinfo()` و متغیرهای محیطی را نمایش نمی‌دهد.
- فایلی را نمی‌خواند.
- به دیتابیس وصل نمی‌شود.
- چیزی نمی‌نویسد (جز حذف خودش).

> اگر نسخهٔ PHP دامنه با نسخهٔ پیش‌فرض متفاوت تنظیم شده، اسکریپت نسخهٔ **همان دامنه** را گزارش می‌کند.

## روش B: موارد قابل مشاهده در پنل DirectAdmin

| # | سؤال | محل معمول در DirectAdmin | پاسخ |
|---|---|---|---|
| 1 | نسخه‌های PHP **قابل انتخاب** برای دامنه | Account Manager › Domain Setup › (دامنه) › PHP Version، یا «Select PHP version» (CloudLinux) | |
| 2 | امکان فعال‌کردن افزونه‌های `intl`، `sodium`، `gd`/`imagick`، `pdo_mysql`، `fileinfo`، `zip` | Select PHP version › Extensions | |
| 3 | نوع و نسخهٔ دیتابیس (MySQL یا MariaDB، مثلاً 10.6) | MySQL Management یا صفحهٔ اصلی phpMyAdmin | |
| 4 | دسترسی SSH | Account Manager › SSH Keys یا پرسش از پشتیبانی | |
| 5 | امکان تغییر **Document Root** یا «Custom HTTPD config» یا «Private_html» | Domain Setup › (دامنه) | |
| 6 | امکان ساخت پوشه **کنار** `public_html` (مثلاً `domains/sajadmasoumi.com/app`) | File Manager | |
| 7 | امکان Cron Job و حداقل فاصلهٔ مجاز (مثلاً هر ۱ یا ۵ دقیقه) | Advanced Features › Cron Jobs | |
| 8 | سهمیهٔ فضای دیسک، **Inode**، RAM و CPU (LVE) | صفحهٔ اصلی پنل / Resource Usage | |
| 9 | گواهی SSL فعال و امکان «Force SSL» | SSL Certificates | |
| 10 | امکان ایجاد صندوق ایمیل و SMTP روی دامنه (برای ارسال ایمیل فرم تماس) | E-Mail Manager | |
| 11 | وب‌سرور: Apache، LiteSpeed یا OpenLiteSpeed | از پشتیبانی بپرسید (خروجی اسکریپت هم نشان می‌دهد). | |
| 12 | سیاست پشتیبان‌گیری میزبان (تناوب و مدت نگهداری) | Create/Restore Backups یا پشتیبانی | |
| 13 | نام شرکت میزبان و نوع پلن | | |

## اطلاعات تکمیلی (اختیاری ولی مفید)

- آیا `.htaccess` و `mod_rewrite` پشتیبانی می‌شوند؟ معمولاً بله.
- آیا Git روی هاست فعال است (DirectAdmin Git یا SSH)؟
- آیا دامنهٔ `sajadmasoumi.ir` روی همین هاست است؟ ریدایرکت آن کجا تنظیم شده است؟

## پس از دریافت اطلاعات

تصمیم‌گیری طبق جدول بخش ۳.۱ گزارش Discovery انجام می‌شود:

| شرایط هاست | نتیجه |
|---|---|
| PHP ≥ 8.3 + افزونه‌های لازم | شروع فاز ۲ با Laravel 13 |
| PHP ≤ 8.2 | درخواست ارتقا. PHP 8.2 در ۲۰۲۶-۱۲-۳۱ به پایان پشتیبانی امنیتی می‌رسد. |
| امکان قراردادن کد خارج از `public_html` وجود ندارد | طراحی و **آزمون** روش جایگزین پیش از هر استقرار |
